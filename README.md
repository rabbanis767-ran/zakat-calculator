# Zakat Calculator

## Overview
This is a **live-ready Zakat Calculator** built with **HTML, CSS, and JavaScript**.  
It allows users to calculate their Zakat based on **assets, liabilities, gold, and silver** with options for **Silver or Gold Nisab**.  

It includes:

- Modern UI with color gradients and responsive design
- Nisab threshold notes for guidance
- Built-in calculation logic (2.5% Zakat)
- Publisher information

---

## Features
- Calculate net assets and Zakat
- Shows eligibility based on Nisab
- Easy-to-use input fields for cash, bank, gold, silver, and debts
- Mobile-friendly design
- Live-ready, can be hosted on Netlify or Vercel

---

## Files
- `index.html` – Main page
- `style.css` – Styling
- `script.js` – Zakat calculation logic
- `README.md` – Project description

## How to Run Locally
1. Extract the zip folder.
2. Open terminal/PowerShell in the folder.
3. Run a simple local server (Python required):

```bash
python -m http.server 8000
```

4. Open browser at [http://localhost:8000](http://localhost:8000)

---

## How to Deploy Live
**Option 1: Netlify**
1. Sign up at [Netlify](https://www.netlify.com/).
2. Click "Add New Site" → "Deploy manually".
3. Drag and drop the folder.
4. Netlify will provide a live URL immediately.

**Option 2: Vercel**
1. Sign up at [Vercel](https://vercel.com/).
2. Import project or drag folder.
3. Click "Deploy".
4. Access live URL instantly.

## Notes
- Silver Nisab is recommended for lower threshold and wider eligibility.
- Gold Nisab is optional.
